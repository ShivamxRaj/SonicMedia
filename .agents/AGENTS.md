# Project-Scoped Rules: SonicMedia

## Accuracy & Focus Guidelines
- **Zero Hallucination Policy**: Always inspect actual source code, exact file paths, schemas, and dependencies using file viewing/search tools before making assertions or writing code.
- **Strict Verification**: Never assume API behavior, third-party libraries, or missing files without checking the filesystem.
- **Empirical Debugging**: Base every diagnostic strictly on full error tracebacks and runtime logs.
- **Execution Excellence**: Deliver precise, robust, fully-tested implementation with clean, modern code.
